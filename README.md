# MLDA Notes: Symbol Emergence and Multimodal Concept Formation

This repository contains a structured set of notes and analyses on MLDA (Multimodal Latent Dirichlet Allocation) and its role within the Symbol Emergence Systems framework. The focus is not on reproducing the original published experiment, but on understanding the probabilistic mechanisms that allow MLDA to form latent multimodal concepts and on verifying the behavior of the open‑source LightMLDA implementation.

The notes include:
- a theoretical bridge from symbol emergence to probabilistic generative modeling,
- a detailed walkthrough of Gibbs sampling and its count‑table dynamics,
- hand‑worked examples for tracing individual sampling steps,
- verification of θ (document–topic) and ϕ (topic–word) distributions,
- preliminary observations using the multimodal dataset bundled with LightMLDA.

This repository serves as a conceptual and computational study of how multimodal categories arise from shared latent variables, and how such models relate to broader questions in symbol grounding and emergent meaning.
